01. Introduction to HTML

HTML stands for HyperText Markup Language. It defines the structure of a webpage.

Remember:
HTML = Structure
CSS = Appearance
JavaScript = Interaction

History of HTML

Tim Berners-Lee developed the World Wide Web. The first HTML version appeared in 1993. HTML5 introduced modern multimedia features.

HTML is like the skeleton of a webpage.

02. Basic HTML Structure

<!DOCTYPE html>
<html lang="en">
<head>
    <title>My First Webpage</title>
    <style>Add styles here</style>
    Additional meta tags can go here
                
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to HTML.</p>
</body>
</html>

Purpose of each tag

<!DOCTYPE html> Defines the HTML document type.

<html> Contains the entire HTML document.

<head> Contains page information and metadata.

<title> Sets the browser tab title.

<body> Contains visible webpage content.

Paragraph vs Preformatted Text

The <p> tag creates a paragraph. Extra spaces and line breaks usually collapse.
The <pre> tag preserves spaces and line breaks exactly as written. 

<p>Hello
    World</p>

<pre>Hello
    World</pre>

<br> creates a line break. 

<p>First line<br>Second line</p>

Text Formatting Tags

<b>: Bold text

<strong>: Important text

<i>: Italic text

<em>: Emphasized text

<u>: Underlined text

<sub>: H2O

<sup>: X2

<s>: Old Price

<small>: Small text

Note: <big> is obsolete in modern HTML. Use CSS font-size to enlarge text.

04. HTML Attributes

Attributes provide extra information about an element. They are written inside the opening tag. 

<tagname attribute="value">
    Content
</tagname>

Contenteditable Attribute

Click here to edit this sentence! 

<p contenteditable="true">
    Editable text
</p>

<p contenteditable="false">
    Non-editable text
</p>

true allows editing. false prevents editing through this attribute.

05. Links, Div and Span

Anchor Tag

The <a> tag creates a hyperlink. The href attribute specifies its destination. 

<a href="https://example.com">
    Visit Example
</a>

<a href="https://example.com"
   target="_blank">
    Open in New Tab
</a>

target="_blank" opens the link in a new tab.

06. Images, Audio and Video

Image Tag

src specifies the image location.
alt describes the image.
width and height set its dimensions. 

<img src="sunrise.jpg"
            alt="Beautiful sunrise"
            width="400"
            height="250">

The img tag displays an image.

Audio Tag

<audio src="audio.mp3" controls>
            The controls attribute displays the audio player controls.
            </audio>

The audio tag plays sound.

Video Tag

<video src="nature.mp4"
            controls
            muted
            autoplay
            loop
            poster="preview.jpg"
            width="400">
            Your browser does not support video.
            </video>

controls: Displays play and pause controls.
muted: Starts without sound.
autoplay: Requests automatic playback.
loop: Repeats the video.
poster: Displays a preview image.

Browsers may block autoplay. Muted autoplay is more likely to work.

The video tag plays a video with controls.

07. Last-Minute Quick Revision

img = Image; src = Source; alt = Description.
Multimedia:
audio, video, controls, muted, loop, autoplay, poster.
Formatting:
b, strong, i, em, u, sub, sup, s, small.

Quick Questions

1. Which tag preserves spaces?

Answer: <pre>

2. Which attribute describes an image?

Answer: alt

3. Which tag creates a link?

Answer: <a>

4. Where does visible webpage content go?

Answer: <body>

5. Which attribute allows editing?

Answer: contenteditable="true"
